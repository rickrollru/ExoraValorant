# Exora для Valorant

Трекер для Valorant в одном `.exe`: ранги, уровни и статистика всех игроков в матче, друзья онлайн и
настраиваемый статус в Discord. Логика работы с клиентом Riot портирована из
[VALORANT rank yoinker](https://github.com/zayKenyon/VALORANT-rank-yoinker), интерфейс сделан в стиле Exora.

## Разделы

- **Главная** — профиль: ранг, пик, винрейт, уровень, последние 5 матчей и патчноуты Valorant.
- **Матч** — обе команды на выборе агента и в игре: агент, ник, титул, уровень, ранг и RR, пати.
  Клик по игроку показывает пик, ранг в прошлом акте, винрейт, K/D и HS%.
- **Друзья** — кто в игре, на выборе агента или в лобби, с режимом и рангом.
- **Discord RPC** — что показывать в статусе в игре и в лобби, с живым превью.
- **Настройки** — тема, акцент, оттенок фона, шрифт, масштаб, анимации, язык (RU/EN), режим стримера.

## Сборка

Нужны Windows 10/11 и Visual Studio 2022 с нагрузкой «Разработка классических приложений .NET» (.NET 8).

1. Откройте `ExoraValorant.sln` и запустите проект (F5).
2. Чтобы собрать один `.exe`, щёлкните правой кнопкой по проекту, выберите **Опубликовать**, профиль **Exe**
   и нажмите **Опубликовать**. Или выполните в терминале:

   ```
   dotnet publish src/ExoraValorant/ExoraValorant.csproj -c Release -o publish
   ```

   Готовый файл: `publish/Exora.exe`. Он самодостаточный, .NET на компьютере ставить не нужно.

Каждый пуш в `main` собирается в GitHub Actions: `Exora.exe` лежит в артефактах запуска **Build**.

Интерфейс использует Microsoft Edge WebView2, он уже есть в Windows 10/11. Если его нет, Exora предложит
скачать.

## Discord RPC

Discord показывает «Играет в …» по названию приложения, поэтому нужно своё приложение:

1. Откройте https://discord.com/developers/applications и нажмите **New Application**, назовите его `Valorant`.
2. Скопируйте **Application ID** и вставьте в Exora: **Discord RPC → Client ID**.

Картинки карт, агентов и рангов подставляются по ссылкам с valorant-api.com, загружать их в приложение не нужно.

## Данные

Настройки, кэш и лог лежат в `%LOCALAPPDATA%\Exora`.

Exora не связана с Riot Games и не одобрена ею.
